# 用户首页重构

“附近充电站”成为统一找站入口。首页每张站点卡片显示名称、地址、基准电价、直线距离和空闲数，并提供查看详情、导航、立即充电；无空闲时显示预约 / 排队，无电桩时禁用充电操作。

- 搜索站名或地址，筛选有空闲站点，按距离、空闲数或价格排序。
- 点击充电自动带入本站，选桩后复用原有充电目标确认、预约时段和排队流程；服务端最终校验电桩状态。
- 点击导航打开站点导航窗口，保留首页位置与目的站点，关闭后回到首页；路线预览与外部高德导航沿用原实现。
- 侧栏调整为附近充电站、充电进度、我的订单、消息中心、我的账户。已有充电或预约排队优先恢复，余额显示同步客户端会话。
- 深绿与薄荷绿主题仅应用于用户主窗口；Lucide 插图随程序打包，许可证保留在资源目录。小窗口隐藏装饰横幅，其他业务页面可以滚动查看。
- 保留演示地标定位，距离标为直线距离；不会将演示坐标描述为真实 GPS。

## 验证

Qt 6.4.2 客户端（含 WebEngine）编译通过。`code/tests/discovery_ui.pro` 提供模拟服务端界面回归，测试范围和运行方法见同目录 README。截图使用模拟数据，真实导航路由、预约扣费仍需连接实际服务端与外部服务验证。

## 第二轮：三端统一与功率模拟

- 客户端和服务端启动时通过 `AppTheme` 显式设置浅色调色板，窗口底色统一为 `#F3F7F6`，表格和卡片为白色。覆盖滚动区、空表、页签、日期输入和提示框，避免深色桌面主题造成黑底。
- 所有客户端及服务端表格末列随可用宽度扩展，保留内容列宽和必要的横向滚动，空白区域不再使用系统黑色底色。
- 服务器采用确定性的演示功率模型：启动爬升、双周期小幅波动、后段降功率，功率不超过桩额定值；累计电量由该功率积分得到，推送同一功率供客户端显示。默认显示功率曲线，可切换累计电量和金额。
- 模型假定电池容量 60kWh、初始电量 20%，不代表真实车辆遥测；没有电池数据，因此不宣称真实 SOC。旧服务器未发送功率时不伪造功率点。
- Web 运营大屏使用同一浅绿背景、白卡片和绿色图表，窄屏改为单列布局，每 5 秒刷新。
- Qt 6 客户端、服务端构建成功；9 项客户端检查通过；临时 SQLite 库完成 12 次充电推进、金额一致性、结算和六个后台页面检查；浏览器验证图表显示和 800px 窄屏无横向溢出。

使用更新后的功能需重新构建并重启客户端、服务端，浏览器刷新页面。界面截图和测试日志位于 `docs/ui-preview`，均为测试数据。
