# 预测问题定义与方法体系（充电负荷时序预测）

> 配套：北京模拟数据集（05.北京模拟充电数据集，619 天），方案 v2（Hadoop大数据与智能分析子系统设计方案.md）

---

## 一、问题定义（形式化）

### 问题 1：站点充电负荷预测（核心任务）

给定站点 s 的历史负荷序列 $X_s = {x_{s,1}, x_{s,2}, ..., x_{s,T}}$（15 分钟或小时粒度，单位 kWh），以及外生特征 E_t（天气、节假日、星期、站点类型），预测未来 H 步负荷：

$$\hat{Y}_s = {\hat{x}_{s,T+1}, ..., \hat{x}_{s,T+H}}, \quad H \in {1, 6, 24} \text{（小时）}$$

目标函数（训练损失）：

$$\mathcal{L}_{MSE} = \frac{1}{N}\sum_{i=1}^{N}(\hat{x}_i - x_i)^2, \quad \mathcal{L}_{MAE} = \frac{1}{N}\sum_{i=1}^{N}|\hat{x}_i - x_i|$$

**派生任务**（由负荷预测直接产出）：
- 空闲桩数预测：idlê(s,t) = device_count(s) − x̂(s,t) / P̄（P̄ 为平均单桩功率）
- 高峰时段预警：t* = argmax_t x̂(s,t)，超过阈值触发预警
- 排队预测：queuê(s,t) = max(0, ⌈x̂(s,t)/P̄⌉ − device_count(s))

**训练规模（北京数据）**：47 站 × 619 天 × 24h = 每站 14,856 小时点（15 分钟粒度 59,424 点）；全量 47 站 > 60 万站点-时段样本。

### 问题 2：用户充电需求预测

给定用户 u 的历史充电记录 {(t_{u,1}, kwh_{u,1}), ..., (t_{u,n}, kwh_{u,n})}（时段、电量），预测：
- 下次充电时段 t_{u,n+1}
- 下次充电量 kwh_{u,n+1}

建模为**用户 × 时段矩阵补全**（协同过滤）：R_{u×h}，R_{u,h} = 用户 u 在时段 h 的平均充电行为；预测 = 矩阵分解补全。

## 二、预测方法体系（含借鉴来源）

| 层级 | 方法 | 原理 | 借鉴来源 | 问题 |
|---|---|---|---|---|
| L0 基线 | 小时×星期历史均值 | x̂(t) = mean{x(τ): τ ≡ t (mod 24h), 同星期} | 统计基线 | 问题1（对照） |
| L1 | 时段转移矩阵（马尔可夫） | 状态=时段，P(x_{t+1}|x_t)；预测 = 当前负荷 × 转移矩阵 | **POI 序列推荐 transition-aware（LITH Stage2）** | 问题1 |
| L1 | Prophet | 趋势 + 日/周季节 + 节假日回归器（数据含 49 节假日） | 时序分解 | 问题1 |
| L2 | LSTM 序列模型 | 门控循环网络捕捉长程依赖，多步滚动预测 | **POI 序列推荐 RNN 建模（GRU4Rec 类）** | 问题1 |
| L2 | Transformer 时间注意力（进阶） | 自注意力捕捉跨时段依赖 | **POI 序列推荐注意力机制** | 问题1 |
| L1 | 协同过滤矩阵分解 SVD/ALS | R ≈ U·V^T 补全用户×时段矩阵 | 推荐系统矩阵分解 | 问题2 |
| 创新 | 站点聚类共享建模 | 负荷曲线向量化 + K-Means → 同类站点共享模型参数（冷启动） | 表示学习 Embedding | 问题1 |

### 方法组合逻辑（问题 1 主线）

```
历史负荷序列 + 天气/节假日特征
   ├─ 模式基线（L0）── 可解释、快
   ├─ 时段转移矩阵（L1，借鉴序列推荐的迁移感知）
   ├─ Prophet（L1，节假日效应强）
   └─ LSTM（L2，长程依赖）
   └→ 集成/择优 → 未来 1h/6h/24h 负荷 + 空闲桩 + 高峰预警
```

选择依据：数据含清晰日周期双峰（11-12、17-19 点）、周周期（工作日/周末）、节假日抬升、天气影响——模式基线+Prophet 吃大部分规律；转移矩阵与 LSTM 捕捉"上一时段→下一时段"动态依赖（transition-aware 的迁移点）。

## 三、评估协议

- **划分**：时序数据按时间切分（禁止随机划分）：前 80% 训练（2025-01-01 ~ 约 2026-04-30），后 20% 测试
- **指标**：MAE、RMSE、MAPE(%)、高峰时段命中率（预测高峰 vs 实际高峰同一小时）
- **对比表**：L0 vs L1 vs L2，证明方法增益
