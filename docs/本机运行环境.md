在 Ubuntu 应用菜单搜索“充电平台服务端”“充电平台客户端”“充电平台数据大屏”。先运行服务端，再运行客户端或大屏。管理员初始账号：admin / 123456。

Hadoop 需要时搜索“启动 Hadoop”。它使用现有安装和数据目录，不格式化数据，不依赖 SSH，也不设置开机自启。

命令行入口：

```bash
cd /home/liu/charging
./scripts/start-local.sh server
./scripts/start-local.sh client
./scripts/hadoop-local.sh start
./scripts/hadoop-local.sh status
./scripts/hadoop-local.sh stop
```

## 当前实现边界

此版本 Hadoop/Hive/Spark 内容主要为设计方案。当前大屏实际数据来源仍是 ZIP CSV 和本地 SQLite/Python 聚合，尚无运行中的 Hive/Spark 数据处理链路。Hadoop 环境可用不等于项目已经完成 Hadoop 集成；因此没有安装当前代码不调用的 Hive/Spark。

本次验证覆盖构建、进程启动、数据库、接口和 Hadoop 计算，没有完整人工点验 GUI、在线地图渲染或跨电脑局域网充电流程。
