# 北京真实站点本地导入

2026-09-08 根据 Tesla 官方公开页面核对，新增 12 个真实站点、59 个超级充电桩记录。
原有 12 个站点保留，现有数据库导入后为 24 个站点、147 个桩记录。

逐站名称、地址、桩数、最高功率、车辆开放范围和来源链接见
`code/resources/data/beijing_real_stations_sources.json`。
官方页面为资料快照，不能保证当前营业、空闲或车型兼容状态。

地图位置来自官方页面的百度地图 BD-09 坐标，经近似转换为 GCJ-02 保存；
客户端现有地图模块再转换为 WGS-84 绘制。实际进场请参考运营商入口说明。

真实资料包括站名、地址、桩数和站点最高功率。
本系统的设备编号、空闲状态、1.20 元/度测试价格、预约与充电业务属于模拟，
没有连接或控制真实充电设备；真实费用、兼容车辆及实时可用性以 Tesla 应用为准。
站点地址末尾已注明费用/状态为模拟。

## 使用

重新编译服务端后，首次启动会自动从内置 SQL 资源导入当前数据库。
已有库无需删除或重建。版本标记确保重复启动不重复添加，不覆盖管理员后续修改。

无需编译也可手动运行：

```sh
python3 code/tools/import_real_stations.py /绝对路径/test.db
```

脚本使用 SQLite backup 接口备份原库，再用事务追加数据；失败回滚。
备份位于数据库旁，文件名包含 `before-stations` 和时间戳。
客户端刷新站点即可查询新数据。

站点资料采用服务端本地 SQLite 查询，避免打开列表时等待第三方地点接口。
地图底图和外部路线预览仍需要网络；本次导入不使地图离线化。
在线资料适合定期核实后更新本地快照，不宜在每次打开页面时重新拉取。

验证：`python3 code/tests/station_import_test.py` 使用临时数据库检查追加、幂等和原记录保留。
