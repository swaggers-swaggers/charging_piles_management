## 目标
在不改变业务流程、不编译、不启动程序的前提下，将客户端与管理端所有 Qt Widgets 界面统一为“企业稳重风”：深藏青导航与页头、暖金色强调、浅灰背景、白色卡片、清晰的表格与表单层级。保留现有 `.ui` 登录框和 C++ 动态页面，不强行把业务页面重构为 `.ui`，以降低 Qt 5.15/Qt 6 双版本的改动风险。

## 实施范围

### 1. 统一全局主题
修改 `code/resources/qss/global.qss`：
- 建立统一色板：深藏青背景、次级藏青、暖金主色、浅金 hover/选中态、灰阶文字与边框。
- 优化 `QMainWindow/QDialog/QWidget` 基础字体、背景、文字颜色。
- 重做 `#sidebar`、`#logoLabel`、`#navList`、`#logoutBtn`，让两端导航保持一致，同时使用金色作为当前项和关键状态强调。
- 优化 `#headerBar`、`#headerTitle`、`#headerUser`、`#openWebBtn`，增强页头层次。
- 统一 `#pageTitle`、`#pageHint`、`#sectionTitle`、`#summaryLabel` 等页面层级。
- 统一普通、主操作、危险、成功/次要按钮状态；补充常用 objectName 选择器，如 `#primaryBtn`、`#secondaryBtn`、`#dangerBtn`、`#successBtn`、`#refreshButton`、`#searchButton`、`#addButton`、`#restartButton`、`#freezeButton`、`#settleBtn`。
- 统一 `QLineEdit/QComboBox/QSpinBox/QDoubleSpinBox/QTextEdit` 的高度、圆角、焦点边框、占位文本、下拉列表。
- 统一所有 `QTableWidget/QTableView` 的表头、行高、隔行色、选中态、滚动条，并改善 `QSplitter`、`QStatusBar`、工具提示、卡片与分组容器。
- 为 `QFrame#metricCard`、`QFrame#statCard`、页面卡片容器提供稳重的边框、圆角和轻微层次感；不依赖 Qt 版本特有的阴影 API。

### 2. 登录界面统一
修改 `code/resources/qss/login.qss`，并必要时微调：
- `code/client/LoginDialog.ui`
- `code/server/AdminLoginDialog.ui`

登录框采用深藏青背景、暖金标题/徽标、白色输入卡片、金色主按钮；保留原有控件名称和信号连接，仅补充必要的 `property`/objectName 或尺寸布局调整。确保用户端与管理端登录框视觉一致但文案和字段不变。

### 3. 动态页面控件命名与轻量布局整理
不改变业务逻辑、网络请求和数据字段，只给关键控件补充稳定 objectName，并将少量内联样式迁移到全局 QSS：

客户端：
- `code/client/UserMainWindow.cpp`：为页面栈、右侧内容区、导航项相关容器补命名；保持现有导航顺序和窗口尺寸自适应。
- `code/client/pages/NearbyStationsPage.cpp`：命名区域下拉、地址输入、定位/查询按钮、主表格和详情对话框控件；保留运行时状态颜色，仅统一为新的主题色常量。
- `code/client/pages/NavigationPage.cpp`：命名目的地/出行方式下拉、地图画布、结果提示；将地图背景改为主题匹配的浅藏青灰，保留自绘地图功能。
- `code/client/pages/UserInfoPage.cpp`：命名头像、手机号/余额标签、头像/昵称/充值控件；将默认头像颜色调整为主题灰；让余额/资料区更像卡片。
- `code/client/pages/ChargingPage.cpp`：命名站点下拉、刷新按钮、充电桩表格、订单/进度标签；把错误复用的 `adminLoginBtn` 改为语义化 `settleBtn` 或 `dangerBtn`，避免登录样式串用；将关键数值样式交给 QSS。

服务端：
- `code/server/AdminMainWindow.cpp`：为大屏按钮、页面栈和内容容器补命名。
- `code/server/pages/SalesPage.cpp`：命名时间范围控件与图表宿主容器，统一指标卡和图表区域外壳。
- `code/server/pages/PileStatusPage.cpp`：命名刷新按钮、统计卡片内部标签、图表区域、明细表和汇总标签；减少卡片内联 stylesheet，交由 QSS 控制。
- `code/server/pages/PileManagePage.cpp`：命名刷新/远程重启按钮和表格，远程重启使用危险按钮风格。
- `code/server/pages/StationManagePage.cpp`：命名刷新/新增按钮、左右表格、详情区、区块标题和新增站点对话框字段/按钮；让 `sectionTitle` 与 `pageTitle` 分离。
- `code/server/pages/UserManagePage.cpp`：命名搜索框、搜索/刷新/冻结按钮和表格；冻结使用危险色，解冻可使用成功色。

### 4. 颜色与视觉一致性
- 保留状态语义：空闲/正常、充电中/在线、故障/冻结仍有明显区别，但改用统一的主题绿/金/红色系。
- 不改接口协议、数据库、网络请求、图表数据逻辑。
- 对 Qt Charts 和 Plain* 自绘图表，只调整外层容器与可安全统一的颜色常量；不重写图表引擎。

### 5. 静态验证（不运行）
- 检查所有新增 objectName 与 QSS 选择器拼写一致。
- 检查 `.ui` XML 格式、qmake 资源路径和现有信号槽连接未被破坏。
- 用文本/差异检查确认没有改动业务请求、协议、数据库逻辑。
- 不执行 qmake、make、程序启动或任何运行时测试；最终明确告知你可在 Linux 虚拟机中自行编译运行。
