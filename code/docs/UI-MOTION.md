# 界面动效规范

- `UiMotion::install()` 安装一次应用级事件过滤器，覆盖后续创建的按钮、输入框和弹窗。
- 标题栏支持拖动、最小化、关闭；主窗口支持最大化、还原及双击标题栏切换。右下角保留尺寸调整入口。
- 窗口圆角为 16 px，阴影通过背景绘制，避免在包含地图的窗口上叠加 QGraphicsEffect。
- 页面过渡和可点击控件悬停为 180 ms / OutCubic，点击水波纹为 460 ms / OutCubic。
- 按钮、Bento 卡片、下拉框、数值框和标签栏使用以控件中心为原点的绘制级缩放：悬停时约 1.04 倍，按下时回弹至 0.975 倍。效果不做上移或悬停遮罩，也不修改控件 geometry，因此不会挤动布局。
- 输入框聚焦边框为 1800 ms / InOutSine 呼吸周期，失焦、隐藏或禁用时清理。
- 所有 QAbstractButton 自动产生点击位置水波纹和缩放；自定义可点击卡片应设置 `clickableCard=true`，也可设置 `microInteraction=true`。静态卡片无需伪装为可点击控件。
- 每个控件最多保留 4 个并发水波纹；覆盖层不拦截鼠标事件，不改变布局。
- 充电页使用 40 个低透明度粒子，约 30 fps；上浮使用余弦缓动，隐藏页面时停止计时器，返回时恢复。

验证：`tests/discovery_ui.pro` 包含动态按钮点击坐标、焦点清理、模态弹窗结果、粒子启停和原有业务界面回归；`tests/server_ui.pro` 检查管理端六个页面及计费结算。
